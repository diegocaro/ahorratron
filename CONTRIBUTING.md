# Cómo contribuir a Ahorratrón

¡Gracias por tu interés en contribuir a Ahorratrón!

## Flujo de trabajo

1. Asegúrate de que los tests pasen antes de abrir un PR: `uv run pytest`.
2. Ejecuta `uv run pre-commit run --all-files` para verificar linting y tipos.
3. Abre un Pull Request describiendo el cambio y su motivación.

## Desarrollo asistido por AI

Si usaste una herramienta de IA (Claude, Copilot, ChatGPT u otra) para generar o revisar código que forma parte de un commit, agrégala como co-autora:

```
Co-Authored-By: Claude Haiku 4.5 <noreply@anthropic.com>
```

Al hacerlo, te comprometes a:

- Revisar todo el código generado por la IA.
- Asumir plena responsabilidad por la contribución.
